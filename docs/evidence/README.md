# 对数用的真值快照

放【从外部源导出的真值】，用来把「我们算的」和「人家算的」当场对上。
不是数据管道的一部分，只是证据 —— 所以在版本控制里，体积也刻意保持很小。

## jq_beta_20260831.csv

聚宽因子库 `get_factor_values(['beta'])` 在 2026-08-31 的全市场值，5212 只，无表头
（`code,beta`）。导出语句见 `docs/数据字典/4-按陷阱索引.md` D 节。

**它定案了三件事**（推导脚本：会话内 `beta_reconcile.py`，结论已写入索引）：

1. 聚宽 `beta` 是**标准化后的因子暴露**，横截面 std = 1.0000 —— 不是原始
   CAPM beta（所以 000001.XSHE 是 −1.570046）
2. 它是**快档**：与本地各档重建对数，红利 A 池（332 只）内 Spearman 在
   半衰期 32~63 天最高（0.9643~0.9692），向等权单调降到 0.9334
3. 用它给 A 池排序 **10/10 精确复现聚宽策略给出的清单，连顺序都一样**
   —— 选股差异完全由 beta 口径解释，没有别的来源

**为什么要留这份文件**：先前用「自己按文档重建的半衰期 63 beta」做单变量
隔离，得到「本地等权 +4.95pp/年、p=0.040」的**假结论**（见索引 4 的 G 节）。
真值是唯一能揭穿它的东西。下次要量化任何外部口径的差异，先来这里加一份。
