## 三个数据源的定位

| 源 | 角色 | 权威范围 |
|---|---|---|
| **聚宽 JQ** | 对标基准 + 权威财务指标 | 复现聚宽策略时以它为准；`indicator.*` 是权威值不是本地推算 |
| **通达信 tdx** | 行情 + 股本 | 总股本比聚宽准（会计口径命中 70.6% vs 29.4%） |
| **QMT 迅投** | **实盘执行**；研究阶段只做交叉验证 | 行情与本地逐项吻合；财务能用但**必须显式传 `announce_time`** |
| **本地 lake.db / std / mart** | 唯一的回测入口 | PIT 语义已封装；口径已统一（比率存**小数**、单季在 std 层） |

## 详细推导在哪

本索引只给**结论 + 出处**。推导过程（样本量、命中率、逐只对账）留在原文：

- 聚宽：各 loader 的模块 docstring（`datalake/build/load_jq_*.py`）
- 聚宽因子：[../jqfactor-口径.md](../jqfactor-口径.md)（含**已排除的候选清单**）
- 聚宽速查：[../聚宽接口备忘.md](../聚宽接口备忘.md)
- QMT：`assay/qmt/PROBE_FINDINGS.md`（开头速查表 + 四轮推导）
- QMT 可执行版：`assay/qmt/probe_all.py` 顶部的 `CONFIRMED`（跑一次打印全部定案结论）
- 回测引擎口径：`assay/README.md`、`assay/assay/broker.py` 的模块 docstring

## 维护纪律

**新结论先写进代码注释 / loader docstring（挨着代码），再回来在索引加一行。**
反过来只写索引不写代码，会让两边分叉 —— 而分叉的文档比没有文档更危险。
