# 索引 5 — 外部免费行情接口（实时 / 分时 / 分钟）

> 本地 datalake **只有日线**（`raw_kline_1min` 表建了但 0 行）。要分时/分钟/实时
> 得走外部接口。这一篇把调研结果定案，**下次不要重新试一遍**。
>
> 全部为 2026-09-03 盘中实测（约 11:30，数据当天有效）。
> 出处：`tickflow-stock-panel/backend/app/plugins/stocksdk/`（npm `stock-sdk@2.2.2`，
> 底层就是这些公开接口）、`~/workspace/table-data-viewer/src/extension.ts`。

## 0. 一句话结论

| 要什么 | 用谁 | 为什么 |
|---|---|---|
| **历史分钟**（回填、研究） | **新浪 `quotes.sina.cn`** | **唯一有历史深度**的免费源；口径已核 = 不复权，与本地面板同源 |
| **当日分时**（页面展示） | **东财 `trends2`** ＋腾讯兜底 | 单次一个请求拿全天，带均价线 |
| **实时快照**（自选/持仓刷新） | **腾讯 `qt.gtimg.cn`** | 批量、稳、88 个字段一次给全 |
| 全市场列表 / 日 K | 本地已有 | 别用外部的 |

🔴 **不要用新浪 `hq.sinajs.cn` 做快照** —— 实测 **403**（它的反爬收紧了）。
同一家的 `quotes.sina.cn` 分钟 K 仍然开着 —— **一家两个接口一个封一个不封，
说明随时会变**，所以取不到必须响亮失败并回退，不能静默给空。

## 1. 分渠道索引

### 1.1 新浪 · 分钟 K（**有历史深度，主力**）

```
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData
    ?symbol=sh601857&scale=5&ma=no&datalen=1023
```

| | |
|---|---|
| 免 token | ✅ 不需要 Referer / Cookie |
| `symbol` | `sh601857` / `sz000001` / `sz300375` / `sh688981` / `sh000300`（指数也行）|
| `scale` | 1 / 5 / 15 / 30 / 60（分钟）|
| `datalen` | **上限 1023** |
| 返回 | `[{day:'2026-09-03 11:30:00', open, high, low, close, volume}, …]` 正序 |
| 复权 | **不复权**（实测：60 分钟末根收 11.260 == 面板 `close_bfq` 11.26，≠ 后复权 20.80）|
| 实测耗时 | 130~560 ms；连打 12 次 1.8 秒全过 |

**历史深度（datalen=1023 时）**：

| scale | 条数 | 覆盖交易日 |
|---|---|---|
| 1 分 | 1023 | **5 日** |
| 5 分 | 1023 | **22 日** |
| 15 分 | 1023 | **65 日** |
| 30 分 | 1023 | **129 日** |
| 60 分 | 1023 | **257 日** |

🔴 **`datalen=4000` 返回 `null`** —— 不是报错，是**静默给空**。超上限要自己拦。
🔴 **不支持多 symbol**：`symbol=sh601857,sz000001` 返回 `null`。全市场 5200 只
串行约 11 分钟 —— 所以现实做法是**只取自选/持仓/正在看的那只**。

### 1.2 东方财富 · 当日分时 `trends2`

```
GET https://push2his.eastmoney.com/api/qt/stock/trends2/get
    ?secid=1.601857&fields1=f1,f2,f3,f4,f5,f6,f7,f8
    &fields2=f51,f53,f54,f55,f56,f57,f58&iscr=0&ndays=1
Referer: https://quote.eastmoney.com/     ← 必须带
```

- `secid` = `市场.代码`：**1=沪、0=深/北、116=港**
- `ndays=1~5`，**最多 5 日**
- 返回 `data.trends[]`，每条逗号分隔：
  `时间, 开, 收, 高, 低, 量(手), 额(元), 均价`
  例：`2026-09-03 11:30,11.26,11.27,11.26,1125,1267039.00,11.318`
- `data` 顶层还有 `code / name / preClose / decimal / market / type / status`
- 实测：208 ms / 120~121 条（当日）；`ndays=5` → 1084 条

### 1.3 东方财富 · 分钟 K `kline`

```
GET https://push2delay.eastmoney.com/api/qt/stock/kline/get
    ?secid=1.601857&klt=1&fqt=1&end=20500101&lmt=120
    &fields1=f1,f2,f3,f4,f5&fields2=f51,f52,f53,f54,f55,f56,f57
```

- `klt`：1/5/15/30/60 分，101 日，102 周，103 月
- `fqt`：0 不复权 / 1 前复权 / 2 后复权
- 每条：`时间, 开, 收, 高, 低, 量(手), 额(元)`
- 🔴 **`klt=1` 只有当日**（`lmt=6000` 也只返 120 条 / 1 个交易日）——
  历史分钟别指望它，走新浪。

### 1.4 腾讯 · 实时快照（**批量，快照主力**）

```
GET http://qt.gtimg.cn/q=sh601857,sz000001      ← GBK！
```

返回 `v_sh601857="1~中国石油~601857~11.26~..."`，`~` 分隔 **88 个字段**：

| 位 | 含义 | 位 | 含义 |
|---|---|---|---|
| 1 | 名称 | 2 | 代码 |
| 3 | **现价** | 4 | **昨收** |
| 5 | 今开 | 6 | 成交量(手) |
| 9 | 买一价 | 19 | 卖一价 |
| 30 | 时间戳 `YYYYMMDDHHMMSS` | 33 | 最高 |
| 36 | 成交量(手) | 37 | 成交额相关 |
| 39 | 最低 | 43 | 换手率(%) |
| 44 | **流通市值(亿)** | 45 | **总市值(亿)** |
| 46 | 市净率 | 47 | 市盈率 |

### 1.5 腾讯 · 当日分时 `minute/query`

```
GET https://ifzq.gtimg.cn/appstock/app/minute/query?code=sh601857
Referer: https://gu.qq.com/
```

- 🔴 **主机要用 `ifzq.gtimg.cn`，不能用 `web.ifzq.gtimg.cn`** ——
  后者在本机 **DNS 解析不了**（`nodename nor servname provided`），
  而 `stock-sdk` 源码里写的是 `web.` 那个。
- 返回 `data.sh601857.data.data[]`，每条空格分隔：`时刻 价 成交量(手) 累计成交额(元)`
  例：`1129 11.26 541994 613451491`；同级 `date=20260903`
- 只有当日；实测 669 ms / 121 点

### 1.6 腾讯 · 分钟 K `mkline`

```
GET https://ifzq.gtimg.cn/appstock/app/kline/mkline?param=sh601857,m5,,320
```
`m1/m5/m15/m30/m60`，一次约 **320 条**。深度不如新浪，作兜底。

## 3. 🔴 陷阱（都实测踩过）

### 3.1 东财会**静默限流**，而且封的是主机

连续打十几次 `push2his` 之后：

```
push2his.eastmoney.com        ❌ RemoteDisconnected（连 TCP 都不给）
33.push2his.eastmoney.com     ❌ 同上（编号子域是同一套限流）
63.push2his.eastmoney.com     ❌ 同上
push2delay.eastmoney.com      ✅ 还通            ← 唯一活口
```

- **表现是 `RemoteDisconnected`，不是 HTTP 错误码** —— 看起来像网络抖动，
  实际是被封。第一次遇到会误以为是参数写错了（我就先去怀疑 `fields1` 和 `klt`）。
- **等 45 秒不恢复**，之后每 1.2 秒一次连打 15 次仍然全失败。
- 有时**不断连而是返回 `data: null`**（`push2delay` 上 `klt=5/101` 就这样）——
  这比断连更糟：`json.loads` 成功、`data` 是 `None`，不小心就当成"这只票没数据"。
- **对策**：`push2his` → `push2delay` 自动回退（`table-data-viewer` 的
  `fetchPush2` 就是这么写的，现在知道原因了）；请求要限速；
  **拿到空结果必须当失败处理，不能当"没有数据"**。

★ 新浪与腾讯**不受影响**（我把东财打挂时它们照常返回）—— 三家限流互相独立。

### 3.2 上限超了是**静默给空**，不是报错

| 接口 | 超限行为 |
|---|---|
| 新浪 `datalen=4000` | 返回 `null` |
| 新浪 多 `symbol` | 返回 `null` |
| 东财 限流时 | `data: null` 或 `RemoteDisconnected` |

一律要在调用侧拦，并且**空结果 ≠ 无数据**。

### 3.3 主机名坑

- 腾讯分时要用 `ifzq.gtimg.cn`，`web.ifzq.gtimg.cn` **本机 DNS 解析失败**
  （而 `stock-sdk` 源码写的是 `web.`）。
- 东财 `push2his` 被封时用 `push2delay`。

### 3.4 复权口径

- 新浪分钟、东财 `trends2`、腾讯分时 —— 都是**不复权**。
- 与本地 `panel.open/high/low/close_bfq` **同口径**，可以直接拼。
- ⚠ 拼历史时注意：本地 `close_hfq` 是后复权，**别和分钟数据混着比**。

### 3.5 数据本身的边界

- 这些都是**公开行情接口，非实时撮合**，`stock-sdk` 自己的 README 写着
  「通常有数十秒到数分钟延迟，不适合高频交易决策」。
- 五档只有腾讯快照里有几档，**没有逐笔成交**。

## 4. 已实测可用的完整调用（可直接抄）

```python
import json, urllib.request

UA = {'User-Agent': 'Mozilla/5.0'}
EM = dict(UA, Referer='https://quote.eastmoney.com/')
TX = dict(UA, Referer='https://gu.qq.com/')

def _get(url, hdr, enc='utf-8'):
    r = urllib.request.Request(url, headers=hdr)
    return urllib.request.urlopen(r, timeout=20).read().decode(enc, 'replace')

# 历史分钟（唯一有深度的）
def sina_minute(sym='sh601857', scale=5, n=1023):
    t = _get('https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService'
             '.getKLineData?symbol=%s&scale=%d&ma=no&datalen=%d' % (sym, scale, n), UA)
    d = json.loads(t)
    if not d:                       # 🔴 超限/多 symbol 时是 null，不是报错
        raise RuntimeError('新浪返回空：datalen 超 1023？或传了多个 symbol？')
    return d

# 当日分时（东财；被限流时换 push2delay）
def em_trends(secid='1.601857', ndays=1):
    q = ('/api/qt/stock/trends2/get?secid=%s&fields1=f1,f2,f3,f4,f5,f6,f7,f8'
         '&fields2=f51,f53,f54,f55,f56,f57,f58&iscr=0&ndays=%d' % (secid, ndays))
    for host in ('push2his.eastmoney.com', 'push2delay.eastmoney.com'):
        try:
            d = json.loads(_get('https://' + host + q, EM)).get('data')
            if d and d.get('trends'):
                return d
        except Exception:
            pass                    # RemoteDisconnected = 被封，换主机
    raise RuntimeError('东财分时取不到（两个主机都失败或返回空）')

# 实时快照（批量）
def tx_quote(codes=('sh601857', 'sz000001')):
    t = _get('http://qt.gtimg.cn/q=' + ','.join(codes), UA, 'gbk')
    out = {}
    for line in t.strip().split('\n'):
        if '="' not in line:
            continue
        f = line.split('"')[1].split('~')
        if len(f) > 47:
            out[f[2]] = {'name': f[1], 'close': float(f[3]), 'pre': float(f[4]),
                         'high': float(f[33]), 'low': float(f[39]),
                         'turnover_pct': float(f[43]),
                         'floatmv_yi': float(f[44]), 'pe': float(f[47])}
    return out
```

## 5. 还没做的决定（真要落盘时先想清楚）

1. **存哪个周期** —— 1 分只有 5 天、5 分 22 天、60 分 257 天。
2. **只存自选还是全市场** —— 新浪不支持批量，全市场串行约 11 分钟。
3. 🔴 **分钟数据一旦进 datalake 就会被回测吃到**，而引擎现在是日频的。
   这个决定比取数本身重要得多。
