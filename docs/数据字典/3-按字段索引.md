## 时点字段（as-of）

| 字段 | 语义 | 该用哪个 |
|---|---|---|
| `pub_date` | **公告日**（可见性） | 严格防未来函数用它 |
| `report_date` / `statDate` | **报告期**（有效性） | 财务 as-of 必须**双键**：`pub_date` + `report_date` |

| QMT `ann_dt`/`announce_date`/`anndate`/`report_date`/`first_ann_dt` | ❌ 全 NaN | 名字不对，用上面两个 |

### 🔴 行情组的复权口径不是一致的

| 列 | 复权 | 用在哪 |
|---|---|---|
| `open` `high` `low` `preclose` | **不复权**（原始盘面价） | 报单价、对账券商成交回报 |
| `close_bfq` | **不复权**收盘 | 同上 |
| `close_hfq` `hfq_factor` | **后复权** | 回测（`Bar.close_hfq` / `Lot.shares` 的计价单位） |

同一行里 `open` 和 `close_hfq` 差着一个 `hfq_factor`，混用不报错 —— 只是价格错一个
复权因子（老股能差几十倍）。

**`open` == 当日集合竞价（09:15-09:25）的成交价。** 所以"竞价买入"的成交价可以用
`open` 精确还原，不是近似。实测对账：新澳股份 `603889.XSHG` 2026-09-01 `open = 6.01`，
与券商成交回报 6.010 一致（同一笔的费用也照账单逐项对上，见
`assay/assay/live.py` 的 `day_price` / `fee_breakdown`）。

用途：实盘录入成交时价格留空即按成交日 `open` 回填。**取不到就报错，不退回最近一个
交易日** —— 那会静默把上一交易日的价当今天用。最常见的触发场景是调仓日早上录入，
而当天行情要等晚上 `sync_daily.sh` 跑完才有。

### 🔴 `inc_` 前缀在两个源里含义**相反**

| 源 | 字段 | 含义 |
|---|---|---|
| **QMT / 迅投** | `inc_revenue` / `inc_gross_profit` / `inc_net_profit` | **金额**（主营收入 / 毛利润 / 归母净利润） |
| **聚宽** | `inc_net_profit_year_on_year` / `inc_total_revenue_year_on_year` | **增长率** |

同样的前缀,一个是金额一个是比率。把 QMT 的 `inc_net_profit` 当增长率用会差 11 个数量级
（601398 归母净利 3.64e+11 vs 同比 0.005），大到会立刻发现；反过来把聚宽的当金额用也一样。
危险的是**中间形态**——`du_profit_rate` 这类看不出量级的成品比率，见索引 4。
