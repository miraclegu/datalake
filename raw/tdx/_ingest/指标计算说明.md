# 技术指标计算系统说明

## 概述

本系统为 tdx2db 数据库提供完整的技术指标计算功能，支持常用的50+种技术指标，包括均线、MACD、KDJ、RSI、布林带等。

## 安装要求

- Python 3.8+
- pandas
- numpy
- duckdb

## 使用说明

### 1. 查看支持的指标列表

```bash
python3 calculate_indicators.py --list
```

### 2. 计算单个股票的指标

```bash
python3 calculate_indicators.py --symbol sh600519
```

### 3. 批量计算所有股票的指标

```bash
python3 calculate_indicators.py
```

### 4. 测试模式（限制处理数量）

```bash
python3 calculate_indicators.py --limit 100
```

## 支持的指标列表

### 移动平均线 (MA)
- MA5, MA10, MA20, MA60, MA200, MA250, MA500

### 指数移动平均线 (EMA)
- EMA5, EMA10, EMA12, EMA20, EMA26

### MACD
- MACD, MACD_Signal, MACD_Hist

### RSI (相对强弱指标)
- RSI6, RSI14, RSI24

### KDJ
- KDJ_K, KDJ_D, KDJ_J

### 布林带 (BOLL)
- BOLL_Upper, BOLL_Mid, BOLL_Lower

### ATR (真实波幅)
- ATR

### 成交量指标
- OBV (能量潮)
- VWAP (成交量加权平均价)

### 其他常用指标
- CCI10, CCI20 (顺势指标)
- ROC12 (变动率指标)
- WR (威廉指标)
- DMI (趋向指标: PDI, MDI, ADX)
- BIAS6, BIAS20, BIAS60 (乖离率)
- VOLATILITY_20, VOLATILITY_60 (历史波动率)
- RETURN_5, RETURN_10, RETURN_20, RETURN_60 (收益率)
- DRAWDOWN_20, DRAWDOWN_60 (回撤)

## 数据存储

计算好的指标会保存到数据库的 `stock_indicators` 表中，包含以下字段：

- 基础数据: symbol, date, open, high, low, close, amount, volume
- 技术指标: 上述所有指标

## 使用示例

### 从 Python 中读取指标数据

```python
import duckdb

conn = duckdb.connect('./tdx.db')

# 查询某只股票的指标数据
query = """
    SELECT * FROM stock_indicators
    WHERE symbol = 'sh600519'
    ORDER BY date DESC
    LIMIT 30
"""
df = conn.execute(query).fetchdf()

print(df)
```

### 筛选具有特定指标特征的股票

```python
import duckdb

conn = duckdb.connect('./tdx.db')

# 找出收盘价站上MA20的股票
query = """
    SELECT DISTINCT symbol, date, close, MA20
    FROM stock_indicators
    WHERE date = (SELECT MAX(date) FROM stock_indicators)
      AND close > MA20
      AND MA5 > MA10
    ORDER BY symbol
"""
df = conn.execute(query).fetchdf()

print(df)
```

## tdx2db 功能总结

### 数据获取与管理
- `tdx2db init` - 初始化数据库，导入日线数据
- `tdx2db cron` - 更新数据并计算复权因子
- 复权因子表: `raw_adjust_factor`
- 股本变迁表: `raw_gbbq`
- 股票名称表: `raw_symbol_name`
- 基础行情表: `raw_basic_daily`

### 指标计算
- `calculate_indicators.py` - 计算所有技术指标
- 结果存储在: `stock_indicators`

### 数据查询
- 可通过 Python duckdb 或其他支持的方式查询
- 提供前复权、后复权、不复权视图

## 下一步建议

1. 先运行 `tdx2db cron` 确保复权因子完整
2. 根据需求计算所有股票的指标（可能需要较长时间）
3. 创建自定义的策略回测或选股查询
4. 每日收盘后运行 `tdx2db cron` 和指标计算来更新数据
