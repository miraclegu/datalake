# AmazingData 采集所需（在 Windows / Linux x64 上装，装进独立 venv）
#
#   py -3.13 -m venv venv
#   venv\Scripts\pip install -r requirements.txt
#   venv\Scripts\pip install ..\tgw-1.0.9.2-py3-none-any.whl
#   venv\Scripts\pip install ..\AmazingData-1.1.9-cp313-none-any.whl
#
# 🔴 两个 wheel 必须用网盘下载的离线包装，不要 `pip install AmazingData`
#    —— PyPI 上那个是**另一个项目**（0.0.3，13 KB，与银河的 1.0.24 无关），
#    而 `tgw` 在 PyPI 上根本不存在。装上去"看着成功"，然后 API 全对不上。
# 🔴 不要装进主环境：AmazingData 要 numba>=0.65，会把 numpy 顶到 2.5.x，
#    而回测链与 datalake 构建链都吃 numpy。判据见 datalake/setup_amazing.py。
# 🔴 AmazingData 的 wheel 按 Python 版本分包（cp38~cp314）——
#    装错版本 pip 会直接拒（"not a supported wheel on this platform"），
#    这是唯一一个会明确报错的坑。
